# Classification Lab

A structured workspace and personal knowledge base dedicated to mastering the mechanics of machine learning classification, evaluation metrics, and model validation. 

Instead of just memorizing syntax or calling black-box functions, this repository breaks down the underlying mathematics, array structures, and logical reasoning required to build robust ML pipelines.

## What's Inside

- **`notebooks/`**: Jupyter Notebooks containing hands-on experiments with NumPy, Pandas, and Scikit-Learn.
- **`notes/`**: Comprehensive Markdown cheat sheets covering core concepts, mathematical formulas, and architectural breakdowns.

##  Key Topics Covered

1. **Array Manipulation & NumPy Mechanics**
   - Boolean masking, array reshaping, and vectorised performance optimization.
2. **Scikit-Learn Workflows**
   - Implementing `LogisticRegression`, handling multi-dimensional outputs with `MultiOutputClassifier`, and setting up training/testing splits.
3. **Evaluation Metrics & Mathematics**
   - Derivations and real-world applications of **Mean Squared Error (MSE)**, **$R^2$ Score**, **Precision**, and **Recall**.
4. **Confusion Matrix Architecture**
   - Deconstructing standard binary $2 \times 2$ matrices (`TN`, `FP`, `FN`, `TP`).
   - Analyzing complex multi-label output shapes (`(n_outputs, 2, 2)` 3D arrays) and understanding macro/micro averaging.

## 🎯 Philosophy
Building robust pipelines isn't just about writing code—it's about understanding the system logic beneath the syntax. This lab prioritizes deep conceptual mastery ("knowing") over syntax memorization.
